# File-by-File Guide

## FRONTEND FILES

### 1. index.html
**Location:** `frontend/index.html`
**Purpose:** Main UI structure for the chatbot

**Sections:**
- **Header**
  - Bot avatar & status indicator
  - Language selector (5 languages)
  - Theme toggle (Dark/Light)
  - Admin link (⚙️)

- **Sidebar**
  - Quick topic buttons (generated by JS)
  - Contact information
  - Help links

- **Main Chat Area**
  - Message container (displays chat)
  - Suggestion chips (quick suggestions)
  - Input bar with send button
  - Feedback modal (star rating)

**Key Elements:**
- `id="chatMessages"` - Where messages appear
- `id="userInput"` - Text input field
- `id="sendBtn"` - Send button
- `id="feedbackModal"` - Rating popup
- `id="themeToggle"` - Theme switcher
- `class="lang-btn"` - Language buttons

**Scripts Loaded:**
- `translations.js` - Translation dictionary
- `app.js` - Main logic

### 4. js/app.js
**Location:** `frontend/js/app.js`
**Purpose:** Core frontend logic and interactivity

**Main State Object:**
```javascript
const state = {
  lang: 'en',              // Current language
  theme: 'dark',           // Current theme
  messages: [],            // Chat history
  lastBotMsgId: null,      // For feedback
  pendingRating: null      // Star rating temp
};
```

**Key Functions:**

```javascript
// Initialize app
init()                              // Run on page load

// Message handling
sendMessage(text)                   // Send user message
displayMessage(text, sender)        // Show message in chat
handleBotReply(reply, intent)       // Process bot response

// Language & Theme
changeLanguage(lang)                // Switch language
toggleTheme()                       // Dark/Light toggle

// Feedback
openFeedbackModal()                 // Show rating popup
submitFeedback(rating, comment)     // Save to backend

// Topics
renderTopics()                      // Show quick topics
handleTopicClick(intent)            // Topic button click

// Utility
getTime()                          // Get current time
parseMarkdown(text)                // Bold **text** to <strong>
uid()                              // Generate unique ID
```

**API Calls:**
```javascript
POST /api/chat        - Send message
POST /api/feedback    - Submit rating
GET /api/stats        - Get statistics
POST /api/log         - Save to history
```

**Event Listeners:**
- Send button click
- Enter key press
- Language button clicks
- Theme toggle
- Star rating clicks

### 5. js/translations.js
**Location:** `frontend/js/translations.js`
**Purpose:** Multilingual UI text

**Structure:**
```javascript
const TRANSLATIONS = {
  en: { topics: [...], placeholders: [...], ... },
  hi: { topics: [...], placeholders: [...], ... },
  mr: { topics: [...], placeholders: [...], ... },
  ta: { topics: [...], placeholders: [...], ... },
  te: { topics: [...], placeholders: [...], ... }
};
```

**Keys in Each Language:**
- `topics` - Sidebar quick topics
- `placeholders` - Input field placeholder
- `buttons` - Button labels (Send, Submit, etc.)
- `modal` - Modal text
- `messages` - System messages
- `help` - Help text
- `categories` - FAQ categories

**Usage in app.js:**
```javascript
const t = TRANSLATIONS[state.lang];
console.log(t.topics[0]);  // Get first topic in current language
```

## BACKEND FILES

### 1. server.js
**Location:** `backend/server.js`
**Purpose:** Main Express server setup

**Initialization Steps:**
```javascript
1. Load packages (express, mongoose, cors, dotenv)
2. Load .env variables
3. Create Express app
4. Setup middleware (CORS, JSON parsing)
5. Connect to MongoDB
6. Register all routes
7. Add health check endpoint
8. Add error handler
9. Start server
```

**Middleware:**
```javascript
cors()                              // Allow frontend requests
express.json()                      // Parse JSON bodies
express.urlencoded()                // Parse form data
```

**Routes Registered:**
```javascript
app.use('/api', chatRoutes)         // /api/chat, /api/log
app.use('/api/faqs', faqRoutes)     // FAQ CRUD
app.use('/api/logs', logRoutes)     // Chat history
app.use('/api/feedback', feedbackRoutes)  // Ratings
```

**Additional Endpoints:**
```javascript
GET /api/health                     // Server status check
GET /api/stats                      // Statistics (FAQs, conversations, ratings)
```

**MongoDB Connection:**
```javascript
MONGO_URI = process.env.MONGO_URI || 'mongodb://localhost:27017/campusbot'
```

**Indexes:**
```javascript
FAQSchema.index({ keywords: 'text' });  // Text search on keywords
```

**Model Export:**

### 6. routes/chat.js
**Location:** `backend/routes/chat.js`
**Purpose:** Chatbot logic and message handling

**Key Function: matchFAQ()**
```javascript
// Simple keyword matching "NLP engine"
// Searches user message for FAQ keywords
// Returns highest scoring FAQ match
// Score increases if keyword found in text
// Bonus score for exact matches
```

**POST /api/chat Endpoint:**
```javascript
Input: { message, lang, history }
Process:
  1. Validate input (not empty)
  2. Query FAQ collection
  3. Match user message to FAQ keywords
  4. Get answer in requested language
  5. Return bot reply + intent
Output: { reply, intent, lang }
```

**Fallback Messages:**
- If no match found, returns generic help message
- Different fallback for each language
- Suggests contacting helpdesk

**Language Fallback:**
- Try to get answer in requested language
- If not available, fallback to English
- All FAQs have English by default

```javascript
GET /api/faqs                   // Get all FAQs

  Body: { keywords, category, intent, answers }

  Body: { ...updated fields }

```

**Admin Panel Uses This:**
- Display all FAQs in table
- Add new FAQ
- Edit existing FAQ
- Delete FAQ
